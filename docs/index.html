Editing a model's weights by hand: a follow-up

In November 2026 four MIT CSAIL researchers showed a frontier model editing the weights of Qwen3.5-0.8B directly, with no training, and lifting its MATH-500 score from 7.9% to 48.1%. We checked the released weights byte by byte, ran both models under three sampling settings, measured what the edit costs elsewhere, and then tried the same recipe on a 4B model for a different job.

This is a follow-up, not a takedown. The authors released their logs, their edited model and a diff of the edit. That is why any of this could be checked. The edit is real and is exactly what they released. Our work adds a fair baseline, the costs, and a second model.

Part 1: MIT's 0.8B edit, reproduced and compared fairly

The bytes match the release, but the edit applies six times the projection on one direction per layer, and it changes 130,188 weights, not 131,072. Under the post's settings the unedited model loops to the token cap. With each model at its own best setting, the edit is ahead by +10.5 ± 3.8 points, not +40. It costs 5.5% perplexity and some tool use, and in our agent task it mostly stopped looking things up.

Part 2: our own 4B citation edit

The recipe transfers mechanically. One direction in two layers, at the lowest dose, raised the share of citations that hold from 89.7% to 93.1%. A random direction of the same size did nothing. The test we planned (two runs per arm) came out "not shown". A four-run extension, declared after we had seen that result, showed the gain. The edit does not make the model pass the whole benchmark.

Part 3: a 27B tool reflex in progress

Can the same kind of edit remove a 27B model's habit of calling a tool on a path that an injected instruction planted, while keeping its legitimate tool use? The page describes what is being tested. There are no results yet.

How this was done

Everything ran on one RTX 3090 (24 GB). The experiments were designed and run by Claude agent sessions in Claude Code, under the author's direction. Each decision rule (which edit family, which dose, what counts as "it worked") was written down before the test it judged. Where we changed a plan after seeing a result, the pages say so.

Every number on these pages links to a file in the data folder. The scripts are in the repository's code/ folder. Part 1 can be reproduced from public files. Parts 2 and 3 use a private benchmark, so we publish the method, the edit directions and the aggregate results, not the benchmark itself.
